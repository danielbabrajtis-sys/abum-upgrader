# ABUM Upgrader — стартовый проект

Это стартовый интерфейс Telegram Mini App. Сейчас он **не проводит реальные апгрейды и не хранит инвентарь**. Это намеренно: реальные подарки и баланс должны изменяться только на сервере после проверки Telegram `initData`.

## Файлы
- `index.html` — структура страницы
- `style.css` — оформление
- `app.js` — стартовая логика интерфейса

## Следующий этап
1. Загрузить эти три файла в репозиторий GitHub `abum-upgrader`.
2. Опубликовать статический интерфейс через Cloudflare Pages.
3. Добавить отдельный Telegram-бот и серверный API (Cloudflare Worker + D1).
4. Проверить подпись `Telegram.WebApp.initData` на сервере.
5. Установить команду `/upgrader`, которая отвечает кнопкой `web_app` с URL опубликованного сайта.

## Важно
Не помещайте токен бота, секреты или логику начисления предметов в `app.js` или любой другой публичный файл.
